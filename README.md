# @amlplugins/google-cloud-dataform

Native `@google-cloud/dataform` SDK re-exported under the `@amlplugins` namespace.

> Dataform.

## Install

```bash
npm install @amlplugins/google-cloud-dataform
```

## Use

```ts
import { /* named exports from @google-cloud/dataform */ } from "@amlplugins/google-cloud-dataform";
// or
import sdk from "@amlplugins/google-cloud-dataform";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
